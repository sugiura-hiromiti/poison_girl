* poison_girl is a Rust-based experimental UEFI bootloader/kernel project.

OS development is a journey, and it must be joyful.

** Current goals:

1. Build a UEFI loader
2. Load an ELF kernel from a FAT disk image
3. Boot it under QEMU virt/aarch64
4. Gradually replace shell-dependent tooling with Rust implementations

** Common commands:

- =cargo xt --help= shows the xtask CLI.
- =cargo xt build= builds through the xtask wrapper.
